API Docs

Every endpoint the backend exposes — send a real request and see the response.

GET /health

Liveness probe: the process is up. Does not guarantee the model is ready.

GET /ready

Readiness probe: both models are loaded and able to serve predictions.

POST /predict

Runs face-mesh detection plus gaze and expression classification on a single image. Accepts multipart/form-data with a file field (JPEG, PNG, or WebP, up to 8 MB).
